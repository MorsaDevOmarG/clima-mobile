# Proyecto: Clima - API

- Creación proyecto:
  - **_npx @react-native-community/cli init nombreProyecto_**
- Una vez creado, levantamos el proyecto:
  - **_pnx react-native run-android_**

## Herramientas y/o Tecnologías

- React
- [API](https://openweathermap.org)
- Picker
  - **_npm i @react-native-picker/picker_**
- Animaciones
  - Importamos: _ANIMATED_
- Cerrar Teclado
  - TouchableWithoutFeedback
  - Keyboard.dismiss();
    - Esto funciona para cerrar el teclado cuando se da click fuera del _INPUT_
